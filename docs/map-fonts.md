# Map lettering

Waypoint bundles MapLibre SDF glyphs for roads, localities and places. The phone,
quest headings and Android Auto share `WorldTypography.kt`; map lettering uses
`World.mapFontName()`. The eleven named map stacks are generated by
`scripts/generate_glyphs.cjs`. Unsupported characters within generated ranges use
bundled Noto Sans; other ranges use the map provider's Noto Sans coverage.

| World or role | Bundled family | Fidelity and source |
|---|---|---|
| Old West map and reading text | Kirsty regular / bold | Identified Red Dead Redemption 2 interface family. |
| Old West titles | Chinese Rocks | Identified display family. |
| Los Santos, San Andreas and Liberty titles | Pricedown Black | GTA display family; readable road labels stay separate. |
| Night City | Rajdhani | Identified Cyberpunk interface family. |
| Green Terminal | Roboto Condensed | Fallout Pip-Boy interface family. |
| Dark Zone | Borda regular / bold | Official Ubisoft Division 2 web assets; the family is also documented by its foundry. |
| Tactical Radar | Stratum 2 regular / bold | Official Counter-Strike web assets. |
| Pixel World | Minecraft Seven | Mojang's content-addressed font resource. |
| 16-bit Quest | Monocraft | An open pixel interpretation, kept distinct from Minecraft Seven. |
| Sea Chart title | Windlass | Base Windlass family; the game's extended custom version is not bundled. Reading text uses Libre Baskerville. |
| Skyrim | Futura Condensed Medium | Identified interface family, extracted from the owner's installed collection. |
| Exclusion Zone | Roboto Condensed | Readable adaptation of the classic S.T.A.L.K.E.R. PDA lettering, not a claim to ship its bitmap font atlas. |
| Other fantasy and antique maps | Libre Baskerville / Cinzel | Readable adaptations. |
| Other technical worlds | Rajdhani / Share Tech Mono | Readable adaptations; not every game's original face. |
| Geographic fallback and native forms | Noto Sans / Android sans-serif | Broad language coverage and legibility. |

The source copies and notices live in
[`third_party/game_fonts/`](../third_party/game_fonts/README.md).
[`sourced-fonts.json`](../third_party/game_fonts/sourced-fonts.json) records the new
files' upstream URLs, versions, preserved name-table notices, conversion notes and
SHA-256 hashes. WOFF sources were decoded to TrueType containers with fontTools;
their outlines and original name records were retained. A public asset URL records
provenance and does not replace the project owner's separately confirmed embedding
and redistribution rights.

Typeface identification and primary evidence:
[The Northern Block on Borda and The Division](https://www.thenorthernblock.com/case-studies/borda-line-revolutionary),
[official Counter-Strike site](https://www.counter-strike.net/cs2),
[Sea of Thieves lettering designer](https://sajatypeworks.com/fonts/seaofthieves/),
[Fallout interface documentation](https://scrivener07.github.io/BGS-Handbook/wiki/fo4/interface/reference/assets/fonts),
[game-family identification index](https://www.gamefontlibrary.com/).

Machine Atlas (NieR:Automata-inspired) uses bundled Noto Sans for both title and reading roles, and Waypoint Classic map glyphs. This is a readable adaptation; no verified original NieR UI font is claimed.
